## 💫 About Me

I'm Ahmad Reza Rezaei — a 25-year-old full-stack developer (26 in three months) based around the WordPress world, currently building at **Sujeh**. I started in custom WordPress themes and plugins, and kept pulling on the thread from there: Go and Python on the backend, React, Vue, and NestJS on everything else. I like taking a site from "it works" to "it's actually fast," and I'm the person who'll happily go two layers deeper into a bug than strictly necessary.

Always chasing the next stack worth learning — let's build something worth showing off.
